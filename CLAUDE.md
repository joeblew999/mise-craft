# mise-craft

## The rule: this repo controls everything it puts on the machine

Anything this repo creates outside its own folder is created by mise or a mise task, and has a
matching mise task that removes it again. Nothing is set up by hand, by another installer, or by a
one-off command.

- Every "do" task has an "undo" task, added in the same change: `<app>:install` / `<app>:uninstall`,
  `<app>:watch` / `<app>:unwatch`, `desktop:install` / `desktop:uninstall`.
- Undo restores the previous state exactly and touches only what this repo added. Tasks that edit a
  shared file (such as Claude Desktop's config) find their own entries by a marker and leave
  everything else byte-for-byte as it was.
- When a change puts something new outside the repo, add it to the "What this repo puts on your
  machine" table in README.md, with the tasks that add and remove it.
- Files the apps write themselves (documents, preferences, control tokens) belong to the apps; undo
  tasks don't delete them.

## Also

- Exact versions only, never `latest`, and keep `mise.lock` current. Installs are idempotent: an
  installed version is never downloaded again.
- Nothing downloads unless it's named: auto-install stays off, and apps are installed with
  `mise run apps:install <app>`.
- mise only: no Homebrew, no ArtCraft Launcher, no manual DMG installs. macOS built-ins called from
  mise tasks and hooks (`hdiutil`, `lsregister`, `open`) are fine.
- `mise.toml` is generated by `scripts/gen-mise-toml.sh`: change the script, then regenerate. Tasks
  live in `mise-tasks/`.
- Each app's MCP server takes different options. Check an app end to end before adding it:
  its headless server to `.mcp.json`, its live server to `mcp-live.json`.
- No desktop app opens unless asked for: live servers stay out of `.mcp.json` and are switched on
  per app with `<app>:watch`.
